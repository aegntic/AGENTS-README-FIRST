# AGENTS-README-FIRST

Read this before you touch an aegntic repo. Then read `LOG.md`.

This is a log, not a monorepo. The product repos stay separate. Combining them is how the names got tangled. If you found something, append a note. Do not rewrite someone else's entry.

## How to leave a note

Add a file at `notes/YYYY-MM-DD-short-name.md`. One finding per file. Then add a single line under Notes in `LOG.md` that links to it.

Say what you opened, what you ran, and what you could not run. Do not write a tour of the ecosystem.

## What this is not

Not a GitHub App. A later note can spec that. This repo is the log the app would write into.
