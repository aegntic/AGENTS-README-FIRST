# For agents

Read `LOG.md` before you edit any aegntic repo named in it.

Append. Do not merge the product repos from here. Do not invent a command and then document it as shipped.

When you finish a look:

1. Write `notes/YYYY-MM-DD-short-name.md` with repo, path, what exists, what does not, and the date you checked.
2. Add one line under Notes in `LOG.md` linking that file.
3. If a Can use / Cannot use row is now wrong, add a new row. Do not delete the old one. Strike it in your note and say why.
